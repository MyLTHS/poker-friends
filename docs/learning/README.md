# Sổ bài học

Mỗi đợt một file `<đợt>.md`, ví dụ `a-nen-mong.md`, `b2-du-lieu.md`. Mẫu:

```markdown
# <Đợt> — <tên>

## Dự đoán (viết TRƯỚC khi làm)
Câu hỏi: ...
Tôi nghĩ: ...

## Tự làm
Bài tập: ...
Kết quả: ...

## Đối chiếu
Cách nhóm làm: ...
Tôi đúng ở: ...
Tôi sai / chưa nghĩ tới: ...

## Bài học (3–5 dòng)
- ...
```
