# Sổ bài học

Các bài đã có (viết dự đoán trước, rồi mới đọc phần "Chuyện đã xảy ra" của mỗi bài):

- [A — Nền móng codebase](a-nen-mong.md)
- [C — Giao diện](c-giao-dien.md): chọn hướng thiết kế, design system, chuyển động không nói dối, ghế đè nhau
- [D — Kiểm thử tổng thể](d-kiem-thu.md): 19 cách gian lận, lỗ dò `command_id`, "bóng ma" khi đóng tab
- [E — Vận hành](e-van-hanh.md): backup phải thử khôi phục, đo trước khi bỏ Redis

Mỗi đợt một file `<đợt>.md`, ví dụ `a-nen-mong.md`, `b2-du-lieu.md`. Mẫu:

```markdown
# <Đợt> — <tên>

## Dự đoán (viết TRƯỚC khi làm)
Câu hỏi: ...
Tôi nghĩ: ...

## Tự làm
Bài tập: ...
Kết quả: ...

## Đối chiếu
Cách nhóm làm: ...
Tôi đúng ở: ...
Tôi sai / chưa nghĩ tới: ...

## Bài học (3–5 dòng)
- ...
```
